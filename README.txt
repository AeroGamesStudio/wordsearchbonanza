Free hosting with GitHub Pages
1. Create a GitHub account and a new public repository (for example "wordsearchbonanza-site").
2. Upload all the files in this folder to the repository.
3. In the repository, open Settings > Pages, choose "Deploy from a branch", pick the main branch and the root folder, and save.
4. After a minute your site is live at https://YOURNAME.github.io/wordsearchbonanza-site/
   Support URL:  https://YOURNAME.github.io/wordsearchbonanza-site/support.html
   Privacy URL:  https://YOURNAME.github.io/wordsearchbonanza-site/privacy.html
Paste those two web addresses into App Store Connect.

Keep the privacy policy in step with the game. If you add analytics, new ad partners, or online features, update privacy.html and your App Privacy answers.
